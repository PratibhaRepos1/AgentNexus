Flag icons vendored from [flag-icons](https://github.com/lipis/flag-icons) (MIT license).

Served as static image files instead of flag emoji because Windows' Segoe UI Emoji
font renders flag emoji as plain two-letter codes (e.g. "NO") rather than actual
flag pictures — macOS renders them fine, which is why the difference only shows up
cross-platform. Real image files render identically everywhere.

To add a new country/currency flag: download the matching `<cc>.svg` from
`flag-icons/flags/4x3/` and drop it in this folder.
